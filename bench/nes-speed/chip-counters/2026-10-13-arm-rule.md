# Issue 77: the design and the pass rule, fixed before the first launch

Written 2026-10-13 06:14 UTC, before any timing launch.

Host: dbhq-arm, 4-core aarch64, Ubuntu 24.04. Chromium 153.0.8010.12 (playwright, CHROME_PATH). .NET SDK 10.0.401 / wasm-tools.

- Baseline: origin/main 5640a57 (= git merge-base origin/main HEAD), exported with git archive to /tmp/nes77/base. After: feat/nes-models c0fdd2d.
- Both: dotnet publish src/Dbhq.Machines.Nes.Wasm -c Release -p:RunAOTCompilation=true -o <folder>, each from its own tree.
- Launch: THREAD_TIME=8 node run-in-browser.mjs <folder> 1 1790000 5000000 5 <region>, from the branch's bench/nes-speed (the same harness for both).
- Order: NTSC first, then PAL. In each region, pairs of launches, baseline then after, 8 pairs. One launch at a time.
- Gate: before every launch, the one-minute load average must be under 1.00; if not, wait (poll every 15 s). The top processes are logged before every launch, and a watch log samples the busiest processes every 15 s throughout.
- Measure: per launch, the median of its eight thread lines' times_real. Per pair, ratio = after / baseline. Per region: median of the 8 ratios, and a 90 per cent percentile bootstrap interval of that median (10,000 resamples, seed 77).
- Rule: PASS if in each region the median ratio >= 0.98 and the interval's lower end >= 0.96. FAIL if in any region the interval's upper end < 0.98. Otherwise INCONCLUSIVE: one more batch of 8 pairs per region (judged on all 16), then stop whatever it says.
- Every launch is kept. A launch that does not print eight thread lines is kept in the log, reported, and its pair is run again.
- Supplementary, not part of the verdict: the native program's instruction count (perf stat -e instructions:u) for both builds, if perf can be enabled; and the differential check on both trees, cmp of the outputs.
- One smoke launch of the after build, NTSC, checks the harness runs on this host before the series; it is kept in the log and not counted. (Added 2026-10-13 06:17 UTC, before it ran.)
