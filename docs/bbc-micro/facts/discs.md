# BBC Micro: discs the site may bundle

Researched on 4 October 2026 for the preset discs on the BBC Micro page. Tags as in the other fact sheets: `[from <url>]` was read directly that day, `[tested]` was run on our machine, `[inferring ...]` joins dots, `[guessing - verify]` needs checking.

**The rule** (`AGENTS.md` rule 4, Dan, 1 October 2026): the site bundles homebrew and freely licensed software; commercial games and application software are load-your-own. So a disc is bundled only when its author or rights holder has written down that it may be redistributed, and the statement is kept with the disc. Hosting by an archive, "abandonware" and "preserved" are not a basis. Non-commercial licences are not used, because DBHQ is a company.

**How they were tested.** In a scratch copy of the machine's test project, with the disc in drive 0 and SHIFT held through power on (the DFS autoboot): each of the discs below boots, its start key starts it, and a movement key visibly changes the picture. Sound was not listened to. None needs sideways RAM, the Tube, the analogue port or Econet [tested]. The scratch harness and screenshots are kept at `~/dbhq-previews/bbc-discs/`, not in the repository.

## Checked when the discs were committed

On 4 October 2026, building the library (`machines/bbc-micro/discs/`), every file was fetched again by hand with curl from the addresses above, and these were found [tested unless marked]:

- **The images are the ones researched.** All seventeen hash to the SHA-256 of the copies the research tested.
- **The licence versions are narrower than "GPL-3.0" above,** and the table now gives them as SPDX ids. The source files of Hard Hat Harry 2, Jet Set Miner, Sparse Invaders, JSnake and the BeebAsm README say "either version 3 of the License, or (at your option) any later version", so those are GPL-3.0-or-later. MazezaM's code says the same, but Malcolm Tyrrell's grant for his puzzles names "the GNU General Public License v3.0" only, so the disc as a whole is GPL-3.0-only. Farmyard Fun and Beeb 6502 test state version 3 and nothing later, and Beat the Bull's repository carries the LGPL version 3 text with no "or later": GPL-3.0-only, GPL-3.0-only and LGPL-3.0-only.
- **Every GPL text the authors ship is the same file,** SHA-256 `8ceb4b9e...65b903`: the one in each source archive and the one on the Farmyard Fun disc. Beat the Bull's repository has the LGPL text only, so the GPL text the LGPL builds on is kept beside it, from gnu.org.
- **Blinkenlights' image is our build,** because its repository has no disc image. Built twice from commit 3d746f10 with its own `make.sh`, BeebAsm at ca2cc5fd and Python 3.12.3, it came out byte for byte the same both times.
- **Jet Set Miner's page credits the BBC Micro port to Sarah Walker, "with contributions from Murray C".** Farmyard Fun's page says it "was originally written in 1989"; the 2008 release is a remaster.
- **MazezaM's title screen says "from the 2002 ZX Spectrum original by Malcolm Tyrrell"**, while its release notes say its puzzles are "the extended set of 'mazezams' provided with the ZX81 version". Both are Tyrrell's; which of his releases the puzzles came from does not change the licence his ZX81 release states [inferring].
- **Every disc also starts from a running machine with SHIFT held through BREAK,** not only through power on as in the research: that is how the page starts them, and `DiscLibraryTests` does it for each one.

## Good, but not clearly redistributable (one question each would settle it)

- **Level 9** (the strongest lead for a classic): "This license applies to the specific implementation of the Level 9 Games, text and code. Licensed under the Apache License, Version 2.0" [from https://github.com/MikeTheTechie/Level9-Public/blob/main/License.txt]; a second file says it "does not grant any rights to the game designs, text, puzzles". The two disagree on "text", and the repository has no BBC interpreter or BBC disc image. Ask Mike Austin whether the grant covers the original BBC releases.
- **Elite.** Braben: "it is not legal, but I do not mind this as long as the copyright messages are intact, and it is not done for commercial gain, but be warned as the other copyright holder may object." [from http://www.iancgbell.clara.net/elite/archive/b9101100.htm]. Braben to Bell in 2005: "You have no such permission ... Please remove these files immediately." [from http://www.iancgbell.clara.net/elite/hypcnt.htm]. Ask both holders in writing; in practice it is load-your-own.
- **Vertigo** (Superior, 1991): the README thanks "Richard Hanson at Superior Interactive for permission to release the source code" and the repository is MIT, but that is permission for the source, not for redistributing the game [from https://github.com/dr-grim/vertigo]. Ask Richard Hanson.
- **Bird Strike**, **b-tracker** (its sample track is a cover of Captain's 1991 work; ship without it), **jBiplane** (hangs on our machine: it polls the analogue converter; a regression check for issue #34), **Wobble Colours**, and freeware titles with no wording on redistribution (Ian Bell's Free Fall and Reversi, Krystal Connection, Mountain Panic, White Light, Beebout, the 0xC0DE games, Stephen Scott's Polymer Picker and Androidz): each needs its author's permission. Sarah Walker and Stephen Scott have already licensed other games, so they are the easiest asks.

## Avoid

Non-commercial or no-copy licences (Hyper Viper CC BY-NC-SA, Cross-Lib, Nursery Rhyme BY-NC-ND, Nyan SID, the Arcade Adventure Design Kit); commercial titles (Repton: The Lost Realms, Zap); Usborne books ("you may not host or distribute the original files"); titles with no rights-holder statement (Acornsoft, the Welcome disc, Chuckie Egg, retail Exile, Galaforce); licensed code with someone else's content (Beeb-NICCC, Bad Apple, the vgm-player demos, Karateka, Bomberman and others); anything whose only basis is a mirror (bbcmicro.co.uk, Stairway to Hell, 8BS); "You're Alan Partridge"; BCP, which needs a second disc.
