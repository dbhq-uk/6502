# The KIM-1

Written 1 October 2026. The first machine, and the first to count towards the
"machines implemented" figure. It sets the pattern the others follow.

## What it is

MOS Technology's 1976 single-board computer: a 6502 at 1 MHz, two 6530 RRIOT
chips (ROM, RAM, I/O and a timer in one), a six-digit seven-segment LED display,
a 23-key keypad, and a teletype interface. There is no screen and no keyboard
beyond the hex keypad. It boots into a monitor in ROM that lets you enter and
run machine code.

## What counts as done

A machine counts when it runs in the browser and an automated acceptance test
passes in CI (see the stage 2 design). For the KIM-1:

- **Acceptance test:** boot the monitor from reset, press keys through the
  keypad lines, enter a short program, run it, and read the result off the six
  digits. The test reads the display as the real board shows it and asserts the
  digits, so it fails if the 6530s, the display scan or the monitor's own
  keypad handling is wrong.
- **In the browser:** a page with the six digits, the keypad, and the reset and
  stop keys, driven by the same machine code.

## Rights (rule 4 in `AGENTS.md`)

The monitor ROM is MOS Technology's, later Commodore's. Dan decided on 1
October 2026 that a ROM is used when its rights are documented. The `rights`
field and the journal state who holds it, where our copy comes from (pinned URL
and sha256, fetched not committed), and what is known about permission,
including that no licence was found if that is so. A `legwork` rights pass was
started and stopped on his instruction; the position is written down from what
was found while building.

## Structure

`src/Dbhq.Machines.Kim1/` (the machine) and `tests/Dbhq.Machines.Kim1.Tests/`
(its acceptance test). The shared browser host is extracted only when the second
machine needs it, per the stage 2 design.

- `Rriot6530`: ROM, RAM, two 8-bit I/O ports with data direction registers, and
  the interval timer, as one chip. Two instances: the 6530-002 holds the monitor
  ROM at the top of memory, the 6530-003 the other half and the I/O the keypad
  and display hang off.
- `Kim1Bus : IBus`: the memory map and address decoding, and one cycle per
  access for the timers.
- `Kim1Keypad` and `Kim1Display`: the key matrix scanned through port lines,
  and the six digit latches the monitor multiplexes.
- Browser: Blazor-free, a plain page driving the machine compiled to WebAssembly
  the way `bench/Dbhq.Cpu6502.WasmBench` does, with a visible keypad and digits.

## Out of scope for the first version

The teletype and serial interface, cassette tape, and the expansion bus. The
registry notes say so.
